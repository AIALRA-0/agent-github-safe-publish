# v1.1.7 攻击回归清单

## 1. 冻结目标

v1.1.7 只修复旧门禁中已经证实的安全缺陷，并关闭旧自动合并；它不宣称实现 v2 转换闭环

## 3. 发布条件

- 每个攻击样例先在旧基线复现错误行为
- 修复后全部攻击回归通过
- 105 项既有测试继续通过
- 旧 `managed-publish --intent auto-merge` 返回明确迁移错误，不创建分支或 Pull Request
- v1.1.7 远端 Commit 和 Tree 与本地认证对象一致

## 4. 非目标

- 不在 v1.1.7 实现数据库、图片、PDF、Office 或二进制转换器
- 不在 v1.1.7 发布 Policy v4
- 不在 v1.1.7 自动修复历史或轮换凭据
- 不在 v1.1.7 修改组织级 Ruleset
